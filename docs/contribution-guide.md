# Contribution Guide

See the top-level `CONTRIBUTING.md` for the canonical process. This page
covers day-to-day mechanics referenced from there:

- Branch naming: `feature/<short-desc>`, `fix/<short-desc>`, `docs/<short-desc>`
- One logical change per PR
- All new packages must ship with a `README.md` following the standard
  Purpose / Responsibility / Dependencies / Future Interfaces template
- Architecture changes require an entry in `architecture/decisions/`
